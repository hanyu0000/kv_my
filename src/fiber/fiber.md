
```lua
┌────────────────────────────┐
│   主协程 (cur_thread_fiber) │
└───────────┬────────────────┘
            │ 调用 Fiber::resume()
            ▼
┌────────────────────────────┐
│   保存主协程上下文 (swapcontext) │
│   切换到子协程 ctx_              │
└───────────┬────────────────┘
            │
            ▼
┌────────────────────────────┐
│      子协程 (Fiber)         │
│  执行回调函数 cb_()          │
└───────────┬────────────────┘
            │ Fiber::yield() 或执行完毕
            ▼
┌────────────────────────────┐
│   保存子协程上下文 (swapcontext) │
│   切回主协程 ctx_               │
└───────────┬────────────────┘
            │
            ▼
┌────────────────────────────┐
│   主协程继续运行            │
└────────────────────────────┘


[协程创建]
    |
    |-- 调用 Fiber() (无参) → 创建主协程，绑定当前线程的执行栈
    |
    |-- 调用 Fiber(cb, stacksize, run_in_scheduler)
            |
            |-- 分配独立栈空间
            |-- 初始化 ucontext
            |-- 设置入口函数 MainFunc
            |
            V
    [协程状态 = READY]

-------------------- 执行阶段 --------------------

[协程 resume()]
    |
    |-- 检查状态 != TERM && != RUNNING
    |-- SetThis(this)  → 设置当前运行的协程
    |-- 状态 = RUNNING
    |
    |-- 根据 isRunInScheduler 判断：
    |       |-- true  → swapcontext(调度器主协程 → 当前子协程)
    |       |-- false → swapcontext(线程主协程 → 当前子协程)
    |
    V
[开始执行 cb_()]

-------------------- 运行结束 --------------------

[MainFunc()]
    |
    |-- 执行 cb_()
    |-- cb_ = nullptr
    |-- 状态 = TERM
    |-- cur.reset() 释放 shared_ptr 引用
    |-- raw_ptr->yield() 切回主协程
    |
    V
[主协程继续运行]

-------------------- 挂起与恢复 --------------------

[子协程 yield()]
    |
    |-- 检查状态 == TERM || == RUNNING
    |-- SetThis(cur_thread_fiber) → 切回主协程
    |-- 如果状态 != TERM，则设置为 READY
    |-- 根据 isRunInScheduler 判断：
    |       |-- true  → swapcontext(当前子协程 → 调度器主协程)
    |       |-- false → swapcontext(当前子协程 → 线程主协程)
    |
    V
[协程被挂起，可再次 resume()]

-------------------- 复用与销毁 --------------------

[协程 reset(cb)]
    |
    |-- 仅允许在 state == TERM 时复用
    |-- 复用原栈空间
    |-- 设置新的入口函数
    |-- 状态 = READY

[协程析构 ~Fiber()]
    |
    |-- 如果是子协程：
    |       |-- 检查状态 == TERM
    |       |-- 释放栈空间
    |
    |-- 如果是主协程：
    |       |-- 检查没有 cb_ 且状态 == RUNNING
    |       |-- 如果当前正在运行，SetThis(nullptr)
    |
    V
[协程生命周期结束]
```
